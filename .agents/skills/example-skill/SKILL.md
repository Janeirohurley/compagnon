# Example Skill

## Purpose

This skill provides a template for creating new skills in Compagnon. It demonstrates the standard structure and conventions.

## When to Use

Use this skill when:
- Creating a new skill from scratch
- Learning about skill structure
- Needing a template for documentation

## How It Works

The skill is triggered when:
1. User mentions keywords related to skills
2. Task patterns match skill purpose
3. Required tools are available

## Examples

### Basic Usage
```
User: "Comment créer un skill?"
→ This skill activates
```

### Advanced Usage
```
User: "Donne-moi un exemple de skill.yaml et skill.md"
→ This skill activates
```

## Configuration

No configuration required for this example skill.

## Notes

- Each skill should have a unique name
- Keep triggers specific to avoid false activations
- Document all required tools in conditions
